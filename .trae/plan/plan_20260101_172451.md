# 待办事项页面开发计划

## 1. 项目分析

### 1.1 项目架构
- **技术栈**：Vue 2 + Vue Router 3 + Element UI
- **路由配置**：`src/router/index.js`
- **组件结构**：使用Element UI组件库，采用模块化开发
- **API请求**：统一通过`src/api/index.js`处理

### 1.2 现有资源
- **待办页面**：已存在`ApprovalTodoList.vue`，包含完整的待办任务列表功能
- **菜单配置**：根据API返回，待办事项页面路径为`/work-list/todo`
- **权限系统**：已实现基于权限标识的权限控制

### 1.3 需求分析
- **页面结构**：新增一个主页面，包含三个tab：待办、已办、已结
- **待办tab**：使用现有`ApprovalTodoList.vue`组件
- **已办tab**：新建`ApprovalDoneList.vue`组件
- **已结tab**：新建`ApprovalClosedList.vue`组件
- **路由配置**：新增对应的路由配置

## 2. 详细开发计划

### 2.1 页面结构设计

**主页面布局**：
```
/work-list/todo
├── 待办（使用现有ApprovalTodoList.vue）
├── 已办（新建ApprovalDoneList.vue）
└── 已结（新建ApprovalClosedList.vue）
```

### 2.2 组件设计

#### 2.2.1 主页面组件：WorkListTodo.vue
- **功能**：包含三个tab切换
- **布局**：使用Element UI的`el-tabs`组件
- **路径**：`src/views/work-list/todo/index.vue`

#### 2.2.2 已办页面组件：ApprovalDoneList.vue
- **功能**：展示已完成的审批任务
- **布局**：复用`ApprovalTodoList.vue`的布局结构
- **API**：调用`getApprovalDoneTasks`（需后端提供）
- **路径**：`src/views/ApprovalDoneList.vue`

#### 2.2.3 已结页面组件：ApprovalClosedList.vue
- **功能**：展示已结束的审批任务
- **布局**：复用`ApprovalTodoList.vue`的布局结构
- **API**：调用`getApprovalClosedTasks`（需后端提供）
- **路径**：`src/views/ApprovalClosedList.vue`

### 2.3 路由配置

**新增路由**：
- 路径：`/work-list/todo`
- 组件：`WorkListTodo.vue`
- 名称：`WorkListTodo`
- 权限标识：`worklist:todo:list`

### 2.4 API设计

**需要后端提供的API**：
- `GET /api/approval/tasks/done`：获取已办任务列表
- `GET /api/approval/tasks/closed`：获取已结任务列表
