# 数据字典变更管理系统开发规划

## 功能概述

基于现有项目结构和数据字典变更流程需求，开发完整的数据字典变更管理系统，包括变更申请、审批、执行和审计功能，规划出不少于50项待办执行，检查测试、规划执行、检查测试。。。。。。

## 技术栈

* **后端**：Spring Boot 2.7 + MyBatis Plus + MySQL 8.0

* **前端**：Vue 2.7 + Element Plus + JavaScript

* **数据库**：MySQL 8.0

* **集成**：现有审批流程系统

## 开发规划

### 一、后端开发

#### 1. 实体类开发

* 创建 `DictTypeChange` 实体类（对应 `biz_ddct_type_change` 表）

* 创建 `DictItemChange` 实体类（对应 `biz_ddct_item_change` 表）

* 创建相关枚举类（变更类型、审批状态、执行状态）

#### 2. Mapper 开发

* 创建 `DictTypeChangeMapper` 接口，实现增删改查和批量操作

* 创建 `DictItemChangeMapper` 接口，实现增删改查和批量操作

* 编写 XML 映射文件，优化复杂查询

#### 3. Service 层开发

* **DictChangeApplyService**：处理变更申请提交、草稿保存、导入功能

* **DictChangeApproveService**：处理审批流程、状态更新

* **DictChangeExecuteService**：处理变更执行、事务管理、回滚机制

* **DictChangeQueryService**：处理变更记录查询、详情获取、统计分析

#### 4. Controller 开发

* **DictChangeController**：提供 RESTful API 接口

* 实现变更申请、审批、执行、查询等接口

* 添加权限控制注解，确保安全访问

#### 5. DTO 和 VO 开发

* 创建 `DictChangeApplyDTO`：变更申请数据传输对象

* 创建 `DictItemChangeDTO`：字典项变更数据传输对象

* 创建 `DictTypeChangeVO`：变更记录展示对象

* 创建 `ChangeDetailVO`：变更详情展示对象

#### 6. 工具类开发

* **ChangeNoGenerator**：生成变更单号

* **DictChangeValidator**：验证变更申请数据

* **DiffUtil**：计算变更差异，用于审批对比

### 二、前端开发

#### 1. 页面开发

* **变更申请页面**：支持字典类型选择、字典项管理、变更原因填写

* **变更审批页面**：支持原始值与变更值对比、审批意见填写

* **变更执行页面**：支持变更执行、结果查看

* **变更记录页面**：支持变更记录查询、筛选、详情查看

#### 2. 组件开发

* **DictItemTable**：字典项表格组件，支持增删改操作

* **ChangeDiffViewer**：变更差异对比组件，高亮显示变更内容

* **ApprovalComment**：审批意见组件

#### 3. API 集成

* 封装后端 API 接口调用

* 实现前端数据缓存策略

* 处理错误和异常情况

### 三、系统集成

#### 1. 审批流程集成

* 与现有审批流程系统集成

* 实现变更申请自动创建审批任务

* 同步审批状态更新

#### 2. 操作日志集成

* 记录变更相关的操作日志

* 确保操作可追溯性

#### 3. 通知系统集成

* 实现变更申请、审批、执行的通知功能

* 支持邮件、系统消息等通知方式

### 四、测试与部署

#### 1. 单元测试

* 编写 Service 层单元测试

* 编写 Controller 层接口测试

* 编写工具类测试

#### 2. 集成测试

* 测试完整的变更流程

* 测试与现有系统的集成

`description` varchar(500) DEFAULT NULL COMMENT '菜单描述',
`created_by` varchar(20) NOT NULL COMMENT '创建人用户编号',
`created_time` datetime NOT NULL DEFAULT CURRENT\_TIMESTAMP COMMENT '创建时间',
`updated_by` varchar(20) DEFAULT NULL COMMENT '更新人用户编号',

`is_deleted` tinyint DEFAULT '0' COMMENT '是否删除：0-否，1-是',
PRIMARY KEY (`id`),
UNIQUE KEY `uk_uuid` (`uuid`),
UNIQUE KEY `uk_menu_code` (`menu_code`),
UNIQUE KEY `uk_resource_key` (`resource_key`),
KEY `idx_parent_menu_code` (`parent_menu_code`),
KEY `idx_menu_type` (`menu_type`),
KEY `idx_resource_type` (`resource_type`),
KEY `idx_path` (`path`(100)),
KEY `idx_status` (`status`)
) ENGINE=InnoDB AUTO\_INCREMENT=1171 DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4\_0900\_ai\_ci COMMENT='菜单/按钮资源表';
