# 数据初始化流程优化

## 1. README.md 文件修改
在 `README.md` 文件的 `-- 初始化数据` 部分，为每个数据表的初始化操作前添加 `TRUNCATE` 语句，确保在插入新数据前清空表中原有数据。需要处理的数据表包括：
- `sys_org`
- `sys_dept`
- `sys_user`
- `sys_user_org`
- `sys_user_dept`
- `sys_role`
- `sys_user_role`
- `sys_menu`

## 2. DataBootstrap.java 文件修改
移除 `DataBootstrap.java` 中的所有数据初始化相关代码，具体包括：
- 清空 `run` 方法中的实现，只保留方法签名
- 移除 `initDictData` 方法
- 移除 `initDictType` 方法
- 移除 `initDictItem` 方法

## 3. MenuBootstrap.java 文件修改
移除 `MenuBootstrap.java` 中的所有数据初始化相关代码，具体包括：
- 清空 `run` 方法中的实现，只保留方法签名
- 移除 `initMenuData` 方法
- 移除 `createMenu` 方法
- 移除 `saveMenu` 方法

## 4. 目标
- 确保数据初始化工作仅通过脚本完成
- 禁用程序启动时自动执行的数据初始化流程
- 不修改已通过脚本初始化的实际数据内容
- 保持代码结构完整性，仅移除数据初始化相关逻辑

## 5. 技术要求
- 严格按照 README.md 中关于数据初始化的说明修改代码
- 确保修改后应用能够正常启动
- 不影响其他功能模块的正常运行
