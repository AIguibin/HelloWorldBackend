# 优化AuthServiceImpl.checkOrgAccess方法执行计划（修正版）

## 1. 需求分析

根据SQL文件和数据权限.md文档，需要优化`checkOrgAccess`方法，使其：
- 正确结合`calculateDataScope`与`dataPermissions`
- 使用更完善的数据权限计算逻辑
- 提高性能，减少不必要的数据库查询
- 保持原有的返回结果结构
- 正确使用数据权限机制

## 2. 核心问题分析

### 2.1 calculateDataScope与dataPermissions的关系

- **calculateDataScope**：计算用户在特定机构下的数据范围类型（1-全部，2-本机构，3-本部门，4-本人，5-自定义）
- **dataPermissions**：用户具体的数据权限规则，包含权限编码、数据名称、实体类型、范围类型、规则类型等

这两个概念是**互补**的：
- `calculateDataScope`提供了数据访问的**层级**
- `dataPermissions`提供了数据访问的**具体规则**

当前实现中，两者没有很好地结合，导致数据权限信息不完整。

### 2.2 结合方式

1. **使用calculateDataScope的结果过滤dataPermissions**：
   - 根据计算出的数据范围类型，过滤掉用户没有权限访问的数据权限规则

2. **将calculateDataScope的结果作为dataPermissions的补充**：
   - 将计算出的数据范围类型添加到dataPermissions中
   - 完善数据权限信息

3. **优化dataPermissions查询**：
   - 根据用户角色和机构信息，只查询相关的数据权限规则
   - 减少不必要的数据传输

## 3. 优化方案

### 3.1 核心优化点

1. **完善calculateDataScope方法**：
   - 考虑角色默认数据范围和特定机构权限范围

2. **优化dataPermissions查询**：
   - 根据计算出的数据范围类型过滤数据权限规则
   - 只查询用户有权访问的数据权限规则

3. **结合calculateDataScope与dataPermissions**：
   - 将数据范围类型添加到dataPermissions中
   - 提供更完整的数据权限信息

4. **添加缓存机制**：

### 3.2 详细实现计划

#### 3.2.1 优化calculateDataScope方法

1. **修改calculateDataScope方法**：
   ```java
   private Integer calculateDataScope(List<Map<String, Object>> userRoles, List<Map<String, Object>> roleOrgScopes, String orgCode) {
       // 默认数据范围为本人
       Integer dataScopeType = DATA_SCOPE_SELF;
       
       // 遍历用户角色，取所有角色中默认数据范围数值最小的（即范围最宽的）
       for (Map<String, Object> role : userRoles) {
           Integer roleDataScope = (Integer) role.get("dataScopeType");
           if (roleDataScope < dataScopeType) {
               dataScopeType = roleDataScope;
           }
       }
       
       // 如果数据范围是自定义（5），则根据角色机构范围进一步判断
       if (dataScopeType == DATA_SCOPE_CUSTOM) {
           // 检查是否有全部机构权限
           boolean hasAllOrgScope = roleOrgScopes.stream()
                   .anyMatch(scope -> "ALL".equals(scope.get("orgCode")));
           
           if (hasAllOrgScope) {
               dataScopeType = DATA_SCOPE_ALL;
           } else {
               // 检查是否有当前机构权限
               boolean hasCurrentOrgScope = roleOrgScopes.stream()
                       .anyMatch(scope -> orgCode.equals(scope.get("orgCode")));
               
               if (hasCurrentOrgScope) {
                   dataScopeType = DATA_SCOPE_ORG;
               } else {
                   dataScopeType = DATA_SCOPE_SELF;
               }
           }
       }
       
       return dataScopeType;
   }
   ```

2. **添加数据范围常量**：
   ```java
   private static final int DATA_SCOPE_ALL = 1; // 全部数据
   private static final int DATA_SCOPE_ORG = 2; // 本机构数据
   private static final int DATA_SCOPE_DEPT = 3; // 本部门数据
   private static final int DATA_SCOPE_SELF = 4; // 本人数据
   private static final int DATA_SCOPE_CUSTOM = 5; // 自定义数据
   ```

#### 3.2.2 优化dataPermissions查询与处理

1. **修改dataPermissions查询逻辑**：
   ```java
   // 13. 查询数据权限规则
   List<Map<String, Object>> dataRules = Collections.emptyList();
   if (!permCodes.isEmpty()) {
       dataRules = userMapper.selectDataRulesByPermCodes(permCodes);
   }
   
   // 14. 结合calculateDataScope结果，处理dataPermissions
   List<Map<String, Object>> dataPermissions = new ArrayList<>();
   if (!dataRules.isEmpty()) {
       // 根据dataScopeType过滤数据权限规则
       dataPermissions = dataRules.stream()
               .filter(rule -> {
                   Integer ruleScopeType = (Integer) rule.get("scopeType");
                   // 根据数据范围类型过滤规则
                   // 例如：如果dataScopeType是2（本机构），则只保留ruleScopeType >= 2的数据权限规则
                   return ruleScopeType != null && ruleScopeType >= dataScopeType;
               })
               .map(rule -> {
                   Map<String, Object> dataPerm = new HashMap<>();
                   dataPerm.put("permCode", rule.get("permCode"));
                   dataPerm.put("dataName", rule.get("ruleName"));
                   dataPerm.put("entityType", rule.get("entityType"));
                   dataPerm.put("scopeType", rule.get("scopeType"));
                   dataPerm.put("ruleType", rule.get("ruleType"));
                   dataPerm.put("status", 1);
                   // 添加计算出的数据范围类型
                   dataPerm.put("calculatedScopeType", dataScopeType);
                   return dataPerm;
               })
               .collect(Collectors.toList());
   }
   ```

2. **优化返回结果中的dataPermissions**：
   - 将处理后的dataPermissions添加到返回结果中
