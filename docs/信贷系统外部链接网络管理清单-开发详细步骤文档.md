# 信贷系统外部链接网络管理清单 - 开发详细步骤文档

## 一、需求概述

### 1.1 功能描述
实现信贷系统外部链接网络管理清单功能，用于管理各环境网络链路信息，包括源IP到目标IP、端口号、连接方式、使用场景等。

### 1.2 功能范围
- ✅ **列表查询**：支持分页、多条件筛选（源环境、目标环境、状态、协议）、关键字搜索
- ✅ **新增链路**：添加新的网络链路记录
- ✅ **编辑链路**：修改现有链路信息
- ✅ **删除链路**：逻辑删除（软删除）
- ✅ **导出Excel**：导出当前筛选条件下的全部数据
- ✅ **打印功能**：前端打印当前列表数据
- ❌ **导入Excel**：暂不实现

### 1.3 技术栈
- **后端**：Spring Boot + MyBatis-Plus + Apache POI
- **前端**：Vue 2 + Element UI
- **数据库**：MySQL 8.0+

## 二、数据库设计

**表名**：`biz_network_link`（业务网络链路表）

**字段说明**：

| 字段名 | 类型 | 长度 | 是否必填 | 说明 | 示例 |

| source_system | varchar | 128 | 是 | 源系统名称 | 信贷核心系统 |
| source_env | varchar | 16 | 是 | 源环境：prod/uat/sit/dev | prod |

| target_system | varchar | 128 | 是 | 目标系统名称 | 统一支付平台 |
| target_env | varchar | 16 | 是 | 目标环境：prod/uat/sit/dev | prod |
| target_host | varchar | 255 | 是 | 目标主机（IP或域名） | 10.2.2.20 |
| target_port | int | - | 是 | 目标端口号（1-65535） | 443 |

| updated_by | varchar | 20 | 否 | 更新人用户编号 | U001 |
| updated_time | datetime | - | 是 | 更新时间 | 2023-10-15 10:00:00 |
| is_deleted | tinyint | - | 是 | 是否删除：0-否，1-是 | 0 |

### 2.2 建表SQL

```sql
CREATE TABLE `biz_network_link` (
  `uuid` varchar(32) NOT NULL COMMENT 'UUID，32位随机字符串',
  `id` bigint unsigned NOT NULL AUTO_INCREMENT COMMENT '自增ID，仅做序号',
  `link_code` varchar(64) NOT NULL COMMENT '链路编号，唯一',
  `link_name` varchar(256) NOT NULL COMMENT '链路名称',
  `source_system` varchar(128) NOT NULL COMMENT '源系统名称',
  `source_env` varchar(16) NOT NULL COMMENT '源环境：prod-生产，uat-UAT测试，sit-SIT测试，dev-开发环境',
  `source_ip` varchar(64) NOT NULL COMMENT '源IP地址',
  `target_system` varchar(128) NOT NULL COMMENT '目标系统名称',
  `target_env` varchar(16) NOT NULL COMMENT '目标环境：prod-生产，uat-UAT测试，sit-SIT测试，dev-开发环境',
  `target_host` varchar(255) NOT NULL COMMENT '目标主机（IP地址或域名）',
  `target_port` int NOT NULL COMMENT '目标端口号（1-65535）',
  `protocol` varchar(32) NOT NULL COMMENT '连接协议：HTTP/HTTPS/TCP/SFTP/MQ等',
  `auth_method` varchar(512) DEFAULT NULL COMMENT '认证方式',
  `scenario` varchar(512) DEFAULT NULL COMMENT '使用场景',
  `description` varchar(1024) DEFAULT NULL COMMENT '链路描述',
  `owner` varchar(64) DEFAULT NULL COMMENT '负责人',
  `status` varchar(16) NOT NULL DEFAULT 'active' COMMENT '链路状态：active-启用中，testing-测试中，disabled-已停用',
  `monitoring_level` varchar(32) DEFAULT NULL COMMENT '监控等级：P0-核心，P1-重要，P2-一般',
  `created_by` varchar(20) NOT NULL COMMENT '创建人用户编号',
  `created_time` datetime NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `updated_by` varchar(20) DEFAULT NULL COMMENT '更新人用户编号',
  `updated_time` datetime DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  `is_deleted` tinyint DEFAULT '0' COMMENT '是否删除：0-否，1-是',
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_uuid` (`uuid`),
  UNIQUE KEY `uk_link_code` (`link_code`),
  KEY `idx_source_env` (`source_env`),
  KEY `idx_target_env` (`target_env`),
  KEY `idx_status` (`status`),
  KEY `idx_protocol` (`protocol`),
  KEY `idx_updated_time` (`updated_time`),
  KEY `idx_is_deleted` (`is_deleted`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_0900_ai_ci COMMENT='信贷系统外部链接网络管理清单表';
```

### 2.3 索引说明
- `uk_uuid`：UUID唯一索引
- `uk_link_code`：链路编号唯一索引
- `idx_source_env`：源环境索引（用于筛选）
- `idx_target_env`：目标环境索引（用于筛选）
- `idx_status`：状态索引（用于筛选）
- `idx_protocol`：协议索引（用于筛选）
- `idx_updated_time`：更新时间索引（用于排序）
- `idx_is_deleted`：删除标记索引（用于过滤已删除数据）

## 三、后端开发步骤

### 3.1 创建实体类（Entity）

**文件路径**：`src/main/java/com/aiguibin/platform/arch/entity/NetExternalLink.java`

**关键点**：
- 使用 `@TableName("biz_network_link")` 指定表名
- 使用 `@TableId(type = IdType.AUTO)` 指定主键自增
- 使用 `@TableField(fill = FieldFill.INSERT)` 和 `@TableField(fill = FieldFill.INSERT_UPDATE)` 自动填充审计字段
- 字段命名使用驼峰，通过 MyBatis-Plus 自动映射下划线字段

**字段验证注解**：
- `link_code`：`@NotBlank`、`@Size(max = 64)`
- `link_name`：`@NotBlank`、`@Size(max = 256)`
- `source_env`、`target_env`：`@NotBlank`、枚举值校验（prod/uat/sit/dev）
- `target_port`：`@NotNull`、`@Min(1)`、`@Max(65535)`
- `protocol`：`@NotBlank`、`@Size(max = 32)`
- `status`：`@NotBlank`、枚举值校验（active/testing/disabled）

### 3.2 创建Mapper接口

**文件路径**：`src/main/java/com/aiguibin/platform/arch/mapper/NetExternalLinkMapper.java`

**关键点**：
- 继承 `BaseMapper<NetExternalLink>`
- 如需自定义查询，可添加方法（本项目主要使用 MyBatis-Plus 的 LambdaQueryWrapper）

### 3.3 创建Service接口

**文件路径**：`src/main/java/com/aiguibin/platform/arch/service/NetExternalLinkService.java`

**方法清单**：
1. `Page<NetExternalLink> page(int page, int size, String sourceEnv, String targetEnv, String status, String protocol, String keyword)` - 分页查询
2. `NetExternalLink getById(Long id)` - 根据ID查询
3. `Long create(NetExternalLink link, String operator)` - 创建链路
4. `boolean update(Long id, NetExternalLink link, String operator)` - 更新链路
5. `boolean delete(Long id, String operator)` - 逻辑删除链路
6. `List<NetExternalLink> listForExport(String sourceEnv, String targetEnv, String status, String protocol, String keyword)` - 导出数据查询（不分页，返回全部符合条件的记录）

### 3.4 创建Service实现类

**文件路径**：`src/main/java/com/aiguibin/platform/arch/service/impl/NetExternalLinkServiceImpl.java`

**关键实现点**：

1. **分页查询**：
   - 使用 `LambdaQueryWrapper` 构建查询条件
   - 默认过滤 `is_deleted = 0`
   - 支持源环境、目标环境、状态、协议精确匹配
   - 支持关键字模糊搜索（链路编号、链路名称、源IP、目标主机、使用场景、描述）
   - 默认按 `updated_time DESC` 排序

2. **创建链路**：
   - 生成UUID（32位随机字符串）
   - 检查 `link_code` 唯一性
   - 设置 `created_by`、`created_time`（自动填充）
   - 设置 `is_deleted = 0`

3. **更新链路**：
   - 检查记录是否存在且未删除
   - 检查 `link_code` 唯一性（排除自身）
   - 设置 `updated_by`、`updated_time`（自动填充）

4. **删除链路**：
   - 逻辑删除：设置 `is_deleted = 1`
   - 设置 `updated_by`、`updated_time`

5. **导出查询**：
   - 复用分页查询的筛选逻辑
   - 不分页，返回全部符合条件的记录
   - 建议限制最大导出数量（如10000条），防止内存溢出

### 3.5 创建Controller

**文件路径**：`src/main/java/com/aiguibin/platform/arch/controller/NetExternalLinkController.java`

**接口清单**：

1. **GET** `/api/net-links` - 分页查询
   - Query参数：`page`（默认1）、`size`（默认10）、`sourceEnv`、`targetEnv`、`status`、`protocol`、`keyword`
   - 返回：`ApiResponse<Page<NetExternalLink>>`

2. **GET** `/api/net-links/{id}` - 根据ID查询详情
   - 返回：`ApiResponse<NetExternalLink>`

3. **POST** `/api/net-links` - 创建链路
   - Body：`NetExternalLink`（JSON）
   - 返回：`ApiResponse<Long>`（返回创建的ID）

4. **PUT** `/api/net-links/{id}` - 更新链路
   - Body：`NetExternalLink`（JSON）
   - 返回：`ApiResponse<Boolean>`

5. **DELETE** `/api/net-links/{id}` - 删除链路（逻辑删除）
   - 返回：`ApiResponse<Boolean>`

**关键点**：
- 使用 `@RestController`、`@RequestMapping("/api/net-links")`
- 从 `HttpServletRequest` 获取 `operator`（当前登录用户编号）
- 使用 `@Validated` 进行参数校验
- 统一返回 `ApiResponse<T>`

### 3.6 创建导出Controller

**文件路径**：`src/main/java/com/aiguibin/platform/arch/controller/NetExternalLinkExportController.java`

**接口清单**：

**GET** `/api/net-links/export` - 导出Excel
- Query参数：`sourceEnv`、`targetEnv`、`status`、`protocol`、`keyword`（与查询接口一致）
- 返回：Excel文件流（`application/vnd.openxmlformats-officedocument.spreadsheetml.sheet`）

**实现要点**：
1. 使用 Apache POI 的 `XSSFWorkbook` 创建Excel
2. 调用 `service.listForExport()` 获取全部数据
3. 设置表头（中文列名）
4. 填充数据行
5. 设置列宽自动调整
6. 设置响应头：
   - `Content-Type: application/vnd.openxmlformats-officedocument.spreadsheetml.sheet`
   - `Content-Disposition: attachment; filename=信贷系统外部链接网络管理清单_yyyyMMdd.xlsx`
7. 使用 `try-with-resources` 确保资源关闭

**Excel列顺序**：
1. 链路编号
2. 链路名称
3. 源系统
4. 源环境
5. 源IP地址
6. 目标系统
7. 目标环境
8. 目标主机
9. 目标端口
10. 连接协议
11. 认证方式
12. 使用场景
13. 链路描述
14. 负责人
15. 链路状态
16. 监控等级
17. 创建时间
18. 更新时间
19. 创建人
20. 更新人

## 四、前端开发步骤

### 4.1 创建API接口文件

**文件路径**：`src/main/webapp/src/api/netLinks.js`

**接口方法**：
```javascript
import request from '../utils/request';

// 分页查询
export const listNetLinks = (params) => request.get('/net-links', { params });

// 根据ID查询详情
export const getNetLink = (id) => request.get(`/net-links/${id}`);

// 创建链路
export const createNetLink = (data) => request.post('/net-links', data, { 
  headers: { 'X-Button-Name': '创建链路' } 
});

// 更新链路
export const updateNetLink = (id, data) => request.put(`/net-links/${id}`, data, { 
  headers: { 'X-Button-Name': '更新链路' } 
});

// 删除链路
export const deleteNetLink = (id) => request.delete(`/net-links/${id}`, { 
  headers: { 'X-Button-Name': '删除链路' } 
});

// 导出Excel
export const exportNetLinks = (params) => request.get('/net-links/export', { 
  params, 
  responseType: 'blob',
  headers: { 'X-Button-Name': '导出Excel' } 
});
```

**在 `src/main/webapp/src/api/index.js` 中导出**：
```javascript
export * from './netLinks';
```

### 4.2 创建Vue页面组件

**文件路径**：`src/main/webapp/src/views/network-link/NetLinkList.vue`

**页面结构**：

1. **顶部操作栏**：
   - 按钮：新增链路、导出Excel、打印表格

2. **筛选区域**：
   - 源环境下拉框：所有环境/生产/UAT/SIT/开发
   - 目标环境下拉框：所有环境/生产/UAT/SIT/开发
   - 状态下拉框：所有状态/启用中/测试中/已停用
   - 协议下拉框：所有协议/HTTP/HTTPS/TCP/SFTP/MQ
   - 关键字搜索框：支持搜索链路编号、名称、IP、场景等

3. **数据表格**：
   - 使用 `el-table` 组件
   - 列：链路编号、链路名称、源系统/环境、源IP、目标系统/环境、目标主机:端口、连接协议、认证方式、使用场景、负责人、链路状态、操作
   - 操作列：编辑按钮、删除按钮
   - 状态列：使用 `el-tag` 显示不同颜色（启用中-绿色、测试中-黄色、已停用-红色）
   - 环境列：使用 `el-tag` 显示不同颜色（生产-红色、UAT-黄色、SIT-蓝色、开发-绿色）

4. **分页组件**：
   - 使用 `el-pagination` 组件
   - 显示总数、每页条数选择、页码跳转

5. **新增/编辑弹窗**：
   - 使用 `el-dialog` 组件
   - 表单字段：链路编号、链路名称、源系统、源环境、源IP、目标系统、目标环境、目标主机、目标端口、连接协议、认证方式、使用场景、链路描述、负责人、链路状态、监控等级

     - 源环境/目标环境：必填、枚举值
     - 目标端口：必填、1-65535

     - 链路状态：必填、枚举值

**导出功能实现**：

## 七、注意事项

1. **链路编号唯一性**：创建和更新时都需要校验
2. **逻辑删除**：所有查询都需要过滤 `is_deleted = 0`
3. **审计字段**：创建和更新时自动填充操作人
4. **导出限制**：建议限制最大导出数量（如10000条），防止内存溢出
5. **环境枚举值**：前端和后端都需要校验环境枚举值
6. **端口范围**：前端和后端都需要校验端口范围（1-65535）
7. **打印功能**：仅前端实现，不涉及后端
8. **Excel文件名**：使用中文文件名，注意URL编码
