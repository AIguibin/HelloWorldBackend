# 数据库实体类修改计划

## 1. 分析结果

通过对比数据库表结构（aaa.sql）和当前实体类，发现以下差异：

### 1.1 SysOrg.java

* 数据库表中没有 `orgType` 字段，但实体类中有

* 数据库表中有 `level` 字段，但实体类中没有

### 1.2 Role.java

* 数据库表字段为 `data_scope_type`，实体类中为 `dataScopeType`，需要添加注解映射

* 实体类中缺少 `is_deleted` 字段

* 实体类中的 `createTime` 和 `updateTime` 字段需要添加注解映射到数据库表的 `created_time` 和 `updated_time`

### 1.3 SysUserOrg.java

* 实体类中 `isMain` 字段名称与数据库表 `is_primary` 不一致

* 实体类缺少多个字段：`orgName`、`position`、`effectiveStart`、`effectiveEnd`、`status`、`description`、`createdBy`、`createdTime`、`updatedBy`、`updatedTime`、`isDeleted`

### 1.4 SysUserDept.java

* 实体类中 `isMain` 字段名称与数据库表 `is_primary` 不一致

* 实体类缺少多个字段：`deptName`、`position`、`effectiveStart`、`effectiveEnd`、`status`、`description`、`createdBy`、`createdTime`、`updatedBy`、`updatedTime`、`isDeleted`

### 1.5 SysRoleOrg.java

* 实体类中 `includeChildren` 字段与数据库表 `org_range_type`、`perm_type` 含义和名称都不匹配

* 实体类缺少多个字段：`orgRangeType`、`permType`、`effectiveStart`、`effectiveEnd`、`status`、`description`、`createdBy`、`createdTime`、`updatedBy`、`updatedTime`、`isDeleted`

## 2. 修改计划

### 2.1 修改 SysOrg.java

* 删除 `orgType` 字段

* 添加 `level` 字段（tinyint 类型，对应 Java Integer）

### 2.2 修改 Role.java

* 将 `dataScopeType` 字段名称调整为 `dataScopeType` 并添加 `@TableField("data_scope_type")` 注解

* 添加 `isDeleted` 字段

* 为 `createTime` 和 `updateTime` 字段添加 `@TableField` 注解映射到 `created_time` 和 `updated_time`

### 2.3 修改 SysUserOrg.java

* 将 `isMain` 字段名称调整为 `isPrimary`

* 添加所有缺失字段：`orgName`、`position`、`effectiveStart`、`effectiveEnd`、`status`、`description`、`createdBy`、`createdTime`、`updatedBy`、`updatedTime`、`isDeleted`

* 添加必要的 `@TableField` 注解

### 2.4 修改 SysUserDept.java

* 将 `isMain` 字段名称调整为 `isPrimary`

* 添加所有缺失字段：`deptName`、`position`、`effectiveStart`、`effectiveEnd`、`status`、`description`、`createdBy`、`createdTime`、`updatedBy`、`updatedTime`、`isDeleted`

* 添加必要的 `@TableField` 注解

### 2.5 修改 SysRoleOrg.java

* 删除 `includeChildren` 字段

* 添加 `orgRangeType` 和 `permType` 字段

* 添加所有缺失字段：`effectiveStart`、`effectiveEnd`、`status`、`description`、`createdBy`、`createdTime`、`updatedBy`、`updatedTime`、`isDeleted`

* 添加必要的 `@TableField` 注解

## 3. 验证步骤

1. 修改所有实体类后，运行项目编译检查是否有语法错误
2. 检查数据库表与实体类字段映射是否正确
3. 验证数据读写操作是否正常

## 4. 预期结果

* 所有实体类与数据库表结构完全匹配

* 项目编译通过，无语法错误

* 数据读写操作正常，无映射异常

## 5. 注意事项

* 所有字段类型必须与数据库表字段类型匹配

* 所有字段名称必须通过 `@TableField` 注解正确映射到数据库表字段

* 所有新增字段必须添加完整的 Javadoc 注释
