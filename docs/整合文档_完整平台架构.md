## 1. 概述

本平台是一个基于Java Spring Boot和Vue框架的企业级应用平台，采用分层架构设计，包含权限管理、审批工作流、数据管理等核心功能模块。平台致力于为企业提供安全、高效、易用的业务处理能力，支持多机构、多角色、多权限的精细化管理。

平台的核心特点包括：

- 基于RBAC的精细化权限管理
- 灵活可配置的审批工作流
- 统一的数据字典和状态管理
- 响应式设计，适配多种设备
- 模块化架构，支持灵活扩展

## 2. 系统架构

### 2.1 分层架构

平台采用分层架构设计，各层之间通过明确的接口进行通信，确保系统的高内聚、低耦合：

| 层级 | 主要职责 | 核心模块 |
|------|----------|----------|
| 前端展示层 | 用户界面展示、交互处理、数据可视化 | 前端组件模块 |
| 后端服务层 | 业务逻辑处理、权限控制、流程管理 | 权限系统模块、审批工作流模块 |
| 数据持久层 | 数据存储、数据访问、实体管理 | 数据库与实体模块 |
| 基础设施层 | 配置管理、日志记录、监控告警 | 系统架构模块 |

### 2.2 模块依赖关系

各模块之间形成清晰的依赖关系，确保系统的整体稳定性和可维护性：

```
前端组件模块
  ↑
  | 依赖API调用
  ↓
权限系统模块 ←→ 审批工作流模块
  ↑         ←→
  | 依赖数据访问
  ↓
数据库与实体模块
  ↑
  | 依赖系统架构
  ↓
系统架构模块
```

## 3. 权限系统模块

### 3.1 数据库设计

权限系统基于RBAC模型，包含14个核心表，用于管理用户、组织、角色和权限关系：

| 表名 | 描述 |
|------|------|
| `sys_user` | 用户信息表 |
| `sys_org` | 组织机构表 |
| `sys_dept` | 部门信息表 |
| `sys_role` | 角色信息表 |
| `sys_permission` | 权限信息表 |
| `sys_user_org` | 用户-组织机构关联表 |
| `sys_user_dept` | 用户-部门关联表 |
| `sys_user_role` | 用户-角色关联表 |
| `sys_role_perm` | 角色-权限关联表 |
| `sys_role_org` | 角色-组织机构关联表 |
| `sys_field_permission` | 字段权限表 |
| `sys_data_permission` | 数据权限表（原sys_data_rule） |
| `sys_time_permission` | 时间权限表 |
| `sys_biz_permission` | 业务规则权限表 |

### 3.2 权限模型

权限系统支持多种权限类型，包括：

1. **访问控制权限**：控制用户是否可以访问某个功能或资源
2. **数据范围权限**：控制用户可以访问的数据范围
3. **字段控制权限**：控制用户可以查看或修改的字段
4. **时间控制权限**：控制用户可以在什么时间访问系统
5. **业务规则权限**：基于业务规则的动态权限控制

### 3.3 实现方案

统一权限管理的核心思想是将所有权限相关的功能封装到一个统一的权限服务中，提供一致的权限检查接口。主要包括：

1. **统一的权限服务接口**：定义了权限检查、权限分配、权限查询等核心方法
2. **模块化的实现**：将权限服务拆分为多个子模块，包括Token管理、权限检查和数据范围计算
3. **灵活的配置**：支持通过配置文件或数据库动态调整权限规则

### 3.4 重构计划

1. **AuthServiceImpl重构**：将其拆分为TokenManager、PermissionChecker、DataScopeCalculator和OrgAccessValidator等模块化组件
2. **SysUserOrgMapper重构**：优化SQL查询，统一数据格式，添加缓存机制，完善错误处理

### 3.5 问题修复

1. **修复数据库查询错误**：移除不存在的'role'字段，确保所有查询字段与数据库表结构匹配
2. **修改checkOrgAccess方法**：确保返回的数据格式符合预期，添加数据格式验证
3. **修改initMenuData()方法**：使其遵循RBDA模型规范，优化菜单数据初始化逻辑
