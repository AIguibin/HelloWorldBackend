# 实现审批流程状态转换算法

## 1. 需求分析
- 当审批流程的当前状态为"02-已提请"，且审批操作类型为"同意"时，需将状态自动更新为"03-审批中"
- 确保算法能够正确读取当前状态值
- 验证状态转换条件
- 准确执行状态更新操作
- 考虑与现有审批流程逻辑的兼容性
- 添加必要的日志记录
- 确保状态转换的原子性和数据一致性

## 2. 实现方案

### 2.2 实现逻辑
1. **读取当前状态**：获取变更记录的当前状态
2. **验证转换条件**：检查当前状态是否为"02-已提请"，操作类型是否为"同意"
3. **执行状态更新**：如果条件满足，将状态更新为"03-审批中"
4. **添加日志记录**：记录状态转换的详细信息
5. **确保原子性**：利用现有的事务管理机制保证状态转换的原子性

### 2.3 代码实现
```java
// 设置审批流程相关字段
record.setFlowId(flow.getFlowId());
record.setCurrentNodeId(firstNode.getNodeId());

// 获取当前状态
String currentStatus = record.getCurrentStatus();
log.info("当前变更记录状态: {}, businessId: {}", currentStatus, businessId);

// 实现状态转换逻辑：当当前状态为"02-已提请"且操作类型为"同意"时，更新为"03-审批中"
if ("02-已提请".equals(currentStatus)) {
    log.info("检测到状态转换条件：当前状态=02-已提请，操作类型=同意，开始更新状态为03-审批中");
    record.setCurrentStatus("03-审批中");
    log.info("状态转换成功：从'02-已提请'更新为'03-审批中'，businessId: {}", businessId);
} else {
    // 保留原有逻辑，根据节点顺序设置状态
    String nextNodeStatus = String.format("审批中-节点%d", firstNode.getNodeOrder());
    record.setCurrentStatus(nextNodeStatus);
    log.info("使用原有状态转换逻辑：设置状态为'{}'，businessId: {}", nextNodeStatus, businessId);
}

record.setApprovalInstanceId(flowInstanceCode);
record.setApprovalStatus("PENDING");
record.setSubmitTime(LocalDateTime.now());
record.setUpdatedBy(userNum);
```
