## 六、SQL查询逻辑
### 1. 查询用户可用机构
```sql
-- 查询用户所有有效机构
SELECT 
    uo.org_code,
    o.org_name,
    o.parent_org_code,
    o.level,
    uo.is_primary,
    uo.position,
    GROUP_CONCAT(DISTINCT d.dept_code) as dept_codes,
    GROUP_CONCAT(DISTINCT d.dept_name) as dept_names
FROM sys_user_org uo
JOIN sys_org o ON uo.org_code = o.org_code
LEFT JOIN sys_user_dept ud ON uo.user_num = ud.user_num AND ud.status = 1
LEFT JOIN sys_dept d ON ud.dept_code = d.dept_code AND d.org_code = uo.org_code
WHERE uo.user_num = 'administrator'
  AND uo.status = 1
  AND o.status = 1
  AND uo.is_deleted = 0
  AND o.is_deleted = 0
  AND (uo.effective_end IS NULL OR uo.effective_end > NOW())
GROUP BY uo.org_code, o.org_name, o.parent_org_code, o.level, uo.is_primary, uo.position
ORDER BY uo.is_primary DESC, o.sort_order;
```

### 2. 查询机构下的权限
```sql
-- 查询用户在指定机构下的权限
WITH user_roles AS (
    SELECT DISTINCT ur.role_code
    FROM sys_user_role ur
    WHERE ur.user_num = 'administrator'
      AND ur.status = 1
      AND ur.is_deleted = 0
      AND (ur.effective_end IS NULL OR ur.effective_end > NOW())
),
org_data_scope AS (
    SELECT 
        ro.org_code,
        ro.perm_type,
        ro.org_range_type,
        CASE 
            WHEN ro.org_range_type = 1 THEN ro.org_code
            WHEN ro.org_range_type = 2 THEN (
                SELECT GROUP_CONCAT(org_code)
                FROM sys_org
                WHERE org_code = ro.org_code 
                   OR parent_org_code = ro.org_code
            )
        END as accessible_orgs
    FROM sys_role_org ro
    WHERE ro.role_code IN (SELECT role_code FROM user_roles)
      AND ro.status = 1
      AND ro.is_deleted = 0
      AND (ro.effective_end IS NULL OR ro.effective_end > NOW())
)
SELECT * FROM org_data_scope WHERE org_code = '01000';
```

## 八、最佳实践建议
1. **会话管理**：
    - 临时token有效期5分钟
    - 正式token有效期2小时
    - token中记录选择的机构代码
2. **缓存策略**：
    - 机构列表缓存24小时
    - 权限信息缓存1小时
    - 用户基础信息不缓存
3. **安全考虑**：
    - 记录机构选择日志
    - 限制机构切换频率
    - 敏感操作需要重新验证
4. **用户体验**：
    - 记住上次选择的机构
    - 提供快速切换入口
    - 显示当前机构名称

这样的设计既支持多机构选择，又保证了权限的精确控制，同时提供了良好的用户体验。
