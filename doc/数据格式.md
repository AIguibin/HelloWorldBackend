``` text
我们根据提供的表结构和数据，整理出所需的数据结构。首先，明确每个部分需要从哪些表中获取数据：

user: 用户基本信息 -> sys_user表

currentOrgDepts: 当前用户所在机构及部门信息 -> sys_org, sys_dept表（根据用户的主机构和主部门，或者用户所在的机构部门列表）

allPermissions: 所有权限（可能是系统所有权限） -> sys_permission表

userPermissions: 用户拥有的权限（直接授权） -> 从sys_user_role关联sys_role_permission，再关联sys_permission，加上其他权限子表（数据、时间、字段、API、业务权限）

rolePermissions: 用户角色所拥有的权限（即通过角色获得的权限） -> sys_user_role关联sys_role_permission，再关联sys_permission

menuPermissions: 菜单权限 -> sys_menu表，结合用户角色关联的权限（sys_role_permission关联sys_perm_resource，资源类型为MENU）

pagePermissions: 页面权限（即菜单和按钮） -> 从sys_menu表中获取类型为P（页面）的菜单，以及其下的按钮（类型为B）。需要结合用户拥有的菜单权限。

dataPermissions: 数据权限 -> sys_data_permission表，通过用户角色关联的权限（sys_role_permission关联sys_perm_resource，资源类型为DATA）获取

timePermissions: 时间权限 -> sys_time_permission表，通过用户角色关联的权限（sys_role_permission关联sys_perm_resource，资源类型为TIME）获取

fieldPermissions: 字段权限 -> sys_field_permission表，通过用户角色关联的权限（sys_role_permission关联sys_perm_resource，资源类型为FIELD）获取

apiPermissions: API权限 -> sys_api_resource表，通过用户角色关联的权限（sys_role_permission关联sys_perm_resource，资源类型为API）获取

bizPermissions: 业务权限 -> sys_biz_permission表，通过用户角色关联的权限（sys_role_permission关联sys_perm_resource，资源类型为BUSINESS）获取

注意：用户拥有的权限（userPermissions）包括直接授予用户的权限和通过角色获得的权限。这里我们分开角色权限和用户权限，但通常用户权限是合并角色权限和直接权限。根据需求，这里userPermissions应该是合并后的。

由于数据结构复杂，我们分步骤查询和组装数据。为了避免循环查询，我们尽量使用批量查询。

假设我们有一个用户登录，用户编号为userNum。

步骤：

查询用户基本信息（sys_user）

查询用户的主机构和主部门，或者用户所属的机构部门列表（sys_user_org, sys_user_dept）

查询用户拥有的角色（sys_user_role）

通过角色获取权限（sys_role_permission关联sys_permission）

获取所有权限（如果需要展示所有权限）

获取菜单、页面、按钮权限（需要根据角色拥有的菜单资源进行过滤）

获取数据、时间、字段、API、业务权限（通过角色拥有的对应资源类型权限）

注意：权限资源关联表sys_perm_resource中关联了权限编码和资源（菜单、API等）。

我们假设已经定义了以下Mapper方法（具体SQL根据表结构编写）：

根据userNum查询用户信息（sys_user）

根据userNum查询用户的主机构和主部门（或者机构部门列表，这里我们根据需求选择当前机构部门，可能是主机构部门）

根据userNum查询用户角色列表（sys_user_role，关联sys_role）

根据角色编码列表查询角色权限（sys_role_permission关联sys_permission）

查询所有权限（sys_permission）

根据角色编码列表查询菜单资源（sys_role_permission关联sys_perm_resource，资源类型为MENU，再关联sys_menu）

查询页面（类型为P的菜单）和按钮（类型为B的菜单）并且根据角色拥有的菜单资源过滤（按钮需要关联父菜单）

根据角色编码列表查询数据权限资源（sys_role_permission关联sys_perm_resource，资源类型为DATA，再关联sys_data_permission）

同理查询时间、字段、API、业务权限。

由于数据量可能不大，我们可以分步查询，但要注意避免N+1问题。

下面我们开始组装数据，假设我们以主机构和主部门作为当前机构部门。

注意：根据提供的表结构，用户有主机构编码（org_code）和主部门编码（dept_code）字段，我们可以直接使用。但用户可能属于多个机构和部门，所以也可以从sys_user_org和sys_user_dept中获取。这里根据需求，我们使用主机构和主部门。

如果用户没有主部门，则部门列表可能为空。

我们按照以下步骤组装数据：

查询用户信息

根据用户信息中的org_code和dept_code查询机构和部门信息

查询用户角色列表

根据角色列表查询角色权限（sys_role_permission）

查询所有权限（根据需求，可能不需要全部，这里按需要展示）

合并用户权限（这里我们假设用户权限就是角色权限，因为用户表没有直接关联权限，都是通过角色）

菜单权限：根据角色拥有的菜单资源，获取菜单列表（类型为M目录，P页面，C组件，B按钮）但通常前端需要的是树形结构，这里我们按页面权限要求，先获取页面和按钮。

页面权限：获取类型为P的菜单，然后获取每个页面下的按钮（类型为B，且parent_menu_code等于页面菜单的menu_code）

数据、时间、字段、API、业务权限：通过角色拥有的对应资源类型权限，获取对应的权限详情。

由于时间关系，我们只给出大致的代码结构，具体SQL需要根据表结构编写。

假设我们已经有了以下Mapper方法：

UserMapper.selectByUserNum(String userNum)
OrgMapper.selectByOrgCode(String orgCode)
DeptMapper.selectByDeptCode(String deptCode) // 或者根据orgCode查询部门列表
UserRoleMapper.selectRolesByUserNum(String userNum) // 返回List<Map>，包含角色编码和角色信息
RolePermissionMapper.selectPermissionsByRoleCodes(List<String> roleCodes) // 返回权限列表，包括权限编码等
PermissionMapper.selectAll() // 所有权限
MenuMapper.selectByRoleCodes(List<String> roleCodes) // 根据角色编码查询有权限的菜单（通过sys_perm_resource关联）
MenuMapper.selectPagesWithButtonsByRoleCodes(List<String> roleCodes) // 查询有权限的页面和按钮
DataPermissionMapper.selectByRoleCodes(List<String> roleCodes) // 数据权限
TimePermissionMapper.selectByRoleCodes(List<String> roleCodes) // 时间权限
FieldPermissionMapper.selectByRoleCodes(List<String> roleCodes) // 字段权限
ApiPermissionMapper.selectByRoleCodes(List<String> roleCodes) // API权限
BizPermissionMapper.selectByRoleCodes(List<String> roleCodes) // 业务权限

注意：菜单、数据、时间、字段、API、业务权限都是通过sys_perm_resource关联到权限编码，然后通过sys_role_permission关联到角色。
```

```java
import java.util.*;
import java.util.stream.Collectors;

/**
 * 用户权限信息组装服务
 */
@Service
@Slf4j
public class UserPermissionService {
    
    @Autowired
    private SysUserMapper sysUserMapper;
    
    @Autowired
    private SysOrgMapper sysOrgMapper;
    
    @Autowired
    private SysDeptMapper sysDeptMapper;
    
    @Autowired
    private SysRoleMapper sysRoleMapper;
    
    @Autowired
    private SysUserRoleMapper sysUserRoleMapper;
    
    @Autowired
    private SysPermissionMapper sysPermissionMapper;
    
    @Autowired
    private SysRolePermissionMapper sysRolePermissionMapper;
    
    @Autowired
    private SysPermResourceMapper sysPermResourceMapper;
    
    @Autowired
    private SysMenuMapper sysMenuMapper;
    
    @Autowired
    private SysApiResourceMapper sysApiResourceMapper;
    
    @Autowired
    private SysDataPermissionMapper sysDataPermissionMapper;
    
    @Autowired
    private SysFieldPermissionMapper sysFieldPermissionMapper;
    
    @Autowired
    private SysBizPermissionMapper sysBizPermissionMapper;
    
    /**
     * 获取用户完整的权限信息
     */
    public Map<String, Object> getUserPermissions(String userNum) {
        Map<String, Object> result = new HashMap<>();
        
        // 1. 用户基本信息
        Map<String, Object> user = getUserInfo(userNum);
        result.put("user", user);
        
        // 2. 用户当前机构部门信息
        String orgCode = (String) user.get("orgCode");
        Map<String, Object> currentOrgDepts = getCurrentOrgDepts(orgCode);
        result.put("currentOrgDepts", currentOrgDepts);
        
        // 3. 所有权限定义
        List<Map<String, Object>> allPermissions = getAllPermissions();
        result.put("allPermissions", allPermissions);
        
        // 4. 用户拥有的角色
        List<Map<String, Object>> userRoles = getUserRoles(userNum);
        
        // 5. 角色权限（通过角色继承的权限）
        List<Map<String, Object>> rolePermissions = getRolePermissions(userRoles);
        result.put("rolePermissions", rolePermissions);
        
        // 6. 用户直接权限（如果有直接授权的话，这里先返回空）
        result.put("userPermissions", new ArrayList<>());
        
        // 7. 菜单和页面权限
        List<Map<String, Object>> pagePermissions = getPagePermissions(userRoles);
        result.put("pagePermissions", pagePermissions);
        
        // 8. 数据权限
        List<Map<String, Object>> dataPermissions = getDataPermissions(userRoles);
        result.put("dataPermissions", dataPermissions);
        
        // 9. 字段权限
        List<Map<String, Object>> fieldPermissions = getFieldPermissions(userRoles);
        result.put("fieldPermissions", fieldPermissions);
        
        // 10. API权限
        List<Map<String, Object>> apiPermissions = getApiPermissions(userRoles);
        result.put("apiPermissions", apiPermissions);
        
        // 11. 业务权限
        List<Map<String, Object>> bizPermissions = getBizPermissions(userRoles);
        result.put("bizPermissions", bizPermissions);
        
        // 12. 时间权限（根据附件，暂时没有数据）
        result.put("timePermissions", new ArrayList<>());
        
        return result;
    }
    
    /**
     * 获取用户基本信息
     */
    private Map<String, Object> getUserInfo(String userNum) {
        // 查询sys_user表
        Map<String, Object> user = sysUserMapper.selectByUserNum(userNum);
        if (user == null) {
            throw new RuntimeException("用户不存在: " + userNum);
        }
        
        // 简化用户信息，只保留关键字段
        Map<String, Object> userInfo = new HashMap<>();
        userInfo.put("userNum", user.get("user_num"));
        userInfo.put("userName", user.get("user_name"));
        userInfo.put("nickname", user.get("nickname"));
        userInfo.put("gender", user.get("gender"));
        userInfo.put("orgCode", user.get("org_code"));
        userInfo.put("deptCode", user.get("dept_code"));
        userInfo.put("email", user.get("email"));
        userInfo.put("phone", user.get("phone"));
        userInfo.put("avatar", user.get("avatar"));
        userInfo.put("status", user.get("status"));
        userInfo.put("isSpecial", user.get("is_special"));
        
        return userInfo;
    }
    
    /**
     * 获取当前机构部门信息
     */
    private Map<String, Object> getCurrentOrgDepts(String orgCode) {
        Map<String, Object> orgDepts = new HashMap<>();
        
        // 获取机构信息
        Map<String, Object> org = sysOrgMapper.selectByOrgCode(orgCode);
        if (org != null) {
            orgDepts.put("orgCode", org.get("org_code"));
            orgDepts.put("orgName", org.get("org_name"));
            orgDepts.put("parentOrgCode", org.get("parent_org_code"));
            orgDepts.put("level", org.get("level"));
            orgDepts.put("status", org.get("status"));
        }
        
        // 获取该机构下的所有部门
        List<Map<String, Object>> depts = sysDeptMapper.selectByOrgCode(orgCode);
        List<Map<String, Object>> deptList = depts.stream()
            .map(dept -> {
                Map<String, Object> deptInfo = new HashMap<>();
                deptInfo.put("deptCode", dept.get("dept_code"));
                deptInfo.put("deptName", dept.get("dept_name"));
                deptInfo.put("managerNum", dept.get("manager_num"));
                deptInfo.put("sortOrder", dept.get("sort_order"));
                deptInfo.put("status", dept.get("status"));
                return deptInfo;
            })
            .collect(Collectors.toList());
        
        orgDepts.put("depts", deptList);
        return orgDepts;
    }
    
    /**
     * 获取所有权限定义
     */
    private List<Map<String, Object>> getAllPermissions() {
        List<Map<String, Object>> permissions = sysPermissionMapper.selectAll();
        return permissions.stream()
            .map(perm -> {
                Map<String, Object> permInfo = new HashMap<>();
                permInfo.put("permCode", perm.get("perm_code"));
                permInfo.put("permName", perm.get("perm_name"));
                permInfo.put("permKey", perm.get("perm_key"));
                permInfo.put("permType", perm.get("perm_type"));
                permInfo.put("actionType", perm.get("action_type"));
                permInfo.put("effectType", perm.get("effect_type"));
                permInfo.put("status", perm.get("status"));
                permInfo.put("description", perm.get("description"));
                return permInfo;
            })
            .collect(Collectors.toList());
    }
    
    /**
     * 获取用户拥有的角色
     */
    private List<Map<String, Object>> getUserRoles(String userNum) {
        // 查询sys_user_role表，关联sys_role表
        List<Map<String, Object>> userRoles = sysUserRoleMapper.selectUserRolesWithDetail(userNum);
        return userRoles;
    }
    
    /**
     * 获取角色权限
     */
    private List<Map<String, Object>> getRolePermissions(List<Map<String, Object>> userRoles) {
        if (userRoles.isEmpty()) {
            return new ArrayList<>();
        }
        
        // 提取角色编码
        List<String> roleCodes = userRoles.stream()
            .map(role -> (String) role.get("roleCode"))
            .collect(Collectors.toList());
        
        // 查询这些角色的所有权限
        List<Map<String, Object>> rolePermissions = sysRolePermissionMapper.selectPermissionsByRoleCodes(roleCodes);
        
        return rolePermissions.stream()
            .map(rp -> {
                Map<String, Object> perm = new HashMap<>();
                perm.put("roleCode", rp.get("role_code"));
                perm.put("permCode", rp.get("perm_code"));
                perm.put("permName", rp.get("perm_name"));
                perm.put("authType", rp.get("auth_type"));
                perm.put("effectiveStart", rp.get("effective_start"));
                perm.put("effectiveEnd", rp.get("effective_end"));
                return perm;
            })
            .collect(Collectors.toList());
    }
    
    /**
     * 获取页面权限（菜单和按钮）
     */
    private List<Map<String, Object>> getPagePermissions(List<Map<String, Object>> userRoles) {
        if (userRoles.isEmpty()) {
            return new ArrayList<>();
        }
        
        // 提取角色编码
        List<String> roleCodes = userRoles.stream()
            .map(role -> (String) role.get("roleCode"))
            .collect(Collectors.toList());
        
        // 1. 查询角色拥有的菜单权限（通过权限资源关联表）
        List<Map<String, Object>> menuResources = sysPermResourceMapper.selectResourcesByRoleCodes(roleCodes, "MENU");
        
        // 提取有权限的菜单编码
        Set<String> allowedMenuCodes = menuResources.stream()
            .map(res -> (String) res.get("resource_key"))
            .collect(Collectors.toSet());
        
        // 2. 获取所有页面菜单（menu_type = 'P'）
        List<Map<String, Object>> pageMenus = sysMenuMapper.selectByMenuType("P");
        
        // 3. 组装页面权限结构
        List<Map<String, Object>> pagePermissions = pageMenus.stream()
            .filter(menu -> allowedMenuCodes.contains(menu.get("resource_key")))
            .map(pageMenu -> {
                Map<String, Object> pagePerm = new HashMap<>();
                pagePerm.put("menu_code", pageMenu.get("menu_code"));
                pagePerm.put("menu_name", pageMenu.get("menu_name"));
                pagePerm.put("menu_type", pageMenu.get("menu_type"));
                pagePerm.put("path", pageMenu.get("path"));
                pagePerm.put("component", pageMenu.get("component"));
                pagePerm.put("resource_key", pageMenu.get("resource_key"));
                
                // 获取该页面的按钮权限
                String parentMenuCode = (String) pageMenu.get("menu_code");
                List<Map<String, Object>> buttonMenus = sysMenuMapper.selectButtonsByParentCode(parentMenuCode);
                
                List<Map<String, Object>> btnsPermissions = buttonMenus.stream()
                    .filter(btn -> allowedMenuCodes.contains(btn.get("resource_key")))
                    .map(btn -> {
                        Map<String, Object> btnPerm = new HashMap<>();
                        btnPerm.put("menu_code", btn.get("menu_code"));
                        btnPerm.put("menu_name", btn.get("menu_name"));
                        btnPerm.put("menu_type", btn.get("menu_type"));
                        btnPerm.put("resource_key", btn.get("resource_key"));
                        return btnPerm;
                    })
                    .collect(Collectors.toList());
                
                pagePerm.put("btnsPermissions", btnsPermissions);
                return pagePerm;
            })
            .collect(Collectors.toList());
        
        return pagePermissions;
    }
    
    /**
     * 获取数据权限
     */
    private List<Map<String, Object>> getDataPermissions(List<Map<String, Object>> userRoles) {
        if (userRoles.isEmpty()) {
            return new ArrayList<>();
        }
        
        List<String> roleCodes = userRoles.stream()
            .map(role -> (String) role.get("roleCode"))
            .collect(Collectors.toList());
        
        // 查询角色拥有的数据权限（通过权限资源关联表）
        List<Map<String, Object>> dataResources = sysPermResourceMapper.selectResourcesByRoleCodes(roleCodes, "DATA");
        
        // 提取权限编码
        List<String> permCodes = dataResources.stream()
            .map(res -> (String) res.get("perm_code"))
            .distinct()
            .collect(Collectors.toList());
        
        // 查询数据权限详情
        List<Map<String, Object>> dataPermissions = sysDataPermissionMapper.selectByPermCodes(permCodes);
        
        return dataPermissions.stream()
            .map(dp -> {
                Map<String, Object> dataPerm = new HashMap<>();
                dataPerm.put("permCode", dp.get("perm_code"));
                dataPerm.put("dataName", dp.get("data_name"));
                dataPerm.put("entityType", dp.get("entity_type"));
                dataPerm.put("scopeType", dp.get("scope_type"));
                dataPerm.put("ruleType", dp.get("rule_type"));
                dataPerm.put("status", dp.get("status"));
                return dataPerm;
            })
            .collect(Collectors.toList());
    }
    
    /**
     * 获取字段权限
     */
    private List<Map<String, Object>> getFieldPermissions(List<Map<String, Object>> userRoles) {
        if (userRoles.isEmpty()) {
            return new ArrayList<>();
        }
        
        List<String> roleCodes = userRoles.stream()
            .map(role -> (String) role.get("roleCode"))
            .collect(Collectors.toList());
        
        // 查询角色拥有的字段权限
        List<Map<String, Object>> fieldResources = sysPermResourceMapper.selectResourcesByRoleCodes(roleCodes, "FIELD");
        
        List<String> permCodes = fieldResources.stream()
            .map(res -> (String) res.get("perm_code"))
            .distinct()
            .collect(Collectors.toList());
        
        // 查询字段权限详情
        List<Map<String, Object>> fieldPermissions = sysFieldPermissionMapper.selectByPermCodes(permCodes);
        
        return fieldPermissions.stream()
            .map(fp -> {
                Map<String, Object> fieldPerm = new HashMap<>();
                fieldPerm.put("permCode", fp.get("perm_code"));
                fieldPerm.put("fieldCode", fp.get("field_code"));
                fieldPerm.put("entityType", fp.get("entity_type"));
                fieldPerm.put("fieldName", fp.get("field_name"));
                fieldPerm.put("fieldAlias", fp.get("field_alias"));
                fieldPerm.put("fieldType", fp.get("field_type"));
                fieldPerm.put("status", fp.get("status"));
                return fieldPerm;
            })
            .collect(Collectors.toList());
    }
    
    /**
     * 获取API权限
     */
    private List<Map<String, Object>> getApiPermissions(List<Map<String, Object>> userRoles) {
        if (userRoles.isEmpty()) {
            return new ArrayList<>();
        }
        
        List<String> roleCodes = userRoles.stream()
            .map(role -> (String) role.get("roleCode"))
            .collect(Collectors.toList());
        
        // 查询角色拥有的API权限
        List<Map<String, Object>> apiResources = sysPermResourceMapper.selectResourcesByRoleCodes(roleCodes, "API");
        
        // 提取有权限的API资源标识
        Set<String> allowedResourceKeys = apiResources.stream()
            .map(res -> (String) res.get("resource_key"))
            .collect(Collectors.toSet());
        
        // 查询所有API资源
        List<Map<String, Object>> allApis = sysApiResourceMapper.selectAll();
        
        // 过滤用户有权限的API
        List<Map<String, Object>> apiPermissions = allApis.stream()
            .filter(api -> allowedResourceKeys.contains(api.get("resource_key")))
            .map(api -> {
                Map<String, Object> apiPerm = new HashMap<>();
                apiPerm.put("apiCode", api.get("api_code"));
                apiPerm.put("apiName", api.get("api_name"));
                apiPerm.put("apiPath", api.get("api_path"));
                apiPerm.put("httpMethod", api.get("http_method"));
                apiPerm.put("resourceKey", api.get("resource_key"));
                apiPerm.put("serviceName", api.get("service_name"));
                apiPerm.put("needAuth", api.get("need_auth"));
                return apiPerm;
            })
            .collect(Collectors.toList());
        
        return apiPermissions;
    }
    
    /**
     * 获取业务权限
     */
    private List<Map<String, Object>> getBizPermissions(List<Map<String, Object>> userRoles) {
        if (userRoles.isEmpty()) {
            return new ArrayList<>();
        }
        
        List<String> roleCodes = userRoles.stream()
            .map(role -> (String) role.get("roleCode"))
            .collect(Collectors.toList());
        
        // 查询角色拥有的业务权限
        List<Map<String, Object>> bizResources = sysPermResourceMapper.selectResourcesByRoleCodes(roleCodes, "BUSINESS");
        
        List<String> permCodes = bizResources.stream()
            .map(res -> (String) res.get("perm_code"))
            .distinct()
            .collect(Collectors.toList());
        
        // 查询业务权限详情
        List<Map<String, Object>> bizPermissions = sysBizPermissionMapper.selectByPermCodes(permCodes);
        
        return bizPermissions.stream()
            .map(bp -> {
                Map<String, Object> bizPerm = new HashMap<>();
                bizPerm.put("permCode", bp.get("perm_code"));
                bizPerm.put("businessName", bp.get("business_name"));
                bizPerm.put("businessType", bp.get("business_type"));
                bizPerm.put("ruleEngine", bp.get("rule_engine"));
                bizPerm.put("status", bp.get("status"));
                return bizPerm;
            })
            .collect(Collectors.toList());
    }
}
```

```java
// 使用示例
@RestController
@RequestMapping("/api/auth")
public class AuthController {
    
    @Autowired
    private UserPermissionService userPermissionService;
    
    /**
     * 获取用户完整权限信息
     */
    @GetMapping("/permissions/{userNum}")
    public Map<String, Object> getUserPermissions(@PathVariable String userNum) {
        return userPermissionService.getUserPermissions(userNum);
    }
    
    /**
     * 用户登录后获取权限信息
     */
    @PostMapping("/login")
    public Map<String, Object> login(@RequestBody LoginRequest request) {
        // 1. 验证用户密码
        // 2. 生成token
        // 3. 获取用户权限信息
        Map<String, Object> permissions = userPermissionService.getUserPermissions(request.getUserNum());
        
        // 4. 返回结果
        Map<String, Object> result = new HashMap<>();
        result.put("token", "生成的JWT token");
        result.put("permissions", permissions);
        return result;
    }
}
```
